# 兩種編輯方式並存時，以程式內的資料為準，記事本 .txt 只是交換用的副本

使用者可以在表格裡直接編輯，也可以用記事本編輯工作區的解密 .txt。兩邊同時有修改時一定要有明確的規則，否則會互相蓋掉。

規則：

1. 程式內的資料（已解析的筆）是唯一的正本。加密存檔時，會同時重新產生 `.lang` 和 `.txt`。
2. 偵測到 .txt 被外部修改時：
   - 程式內**沒有**未存的修改 → 自動重新載入 .txt，並把差異標成 `✎`。
   - 程式內**也有**未存的修改 → 詢問要保留表格的修改，還是改用 .txt 的內容，不會自動合併。
3. 重新載入 .txt 之前，先檢查格式，例如旗標與行數是否吻合（見 [ADR-0001](0001-lang-file-format.md)）。格式壞了就拒絕載入，並指出是第幾行出錯，不讓壞掉的檔案進入正本。
