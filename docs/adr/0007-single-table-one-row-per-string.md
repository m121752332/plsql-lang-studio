# 比對畫面用「單一表格、一列一字串」，不用左右兩個文字窗格

使用者要的是「捲動時 MASTER 和 SLAVE 同步移動、停在同一個名稱位置」。我們把 MASTER 和 SLAVE 放在**同一張表格的同一列**，捲動就天生同步，不需要寫同步捲動的程式，也不可能錯位。code diff 的效果，改由下方詳細區的「字元級差異標色」提供。

**一列 = 一個要翻譯的字串**，不是一筆。一筆有「標題＋提示」，或清單有多個項目時，會拆成多列，「欄位」欄寫明是標題、提示或項目，同一筆的列用相同底色分組。這樣每個格子只對應一個字串，在格子裡編輯時不會改到別的字串。

欄位：`# ｜ 狀態 ｜ 識別碼 ｜ 欄位 ｜ 英文 ｜ MASTER ｜ SLAVE`

狀態：`≠` 不同、`⚠` 疑似漏翻（SLAVE 跟英文相同）、`簡` 殘留簡體字、`◐` 單邊、`✎` 已修改未存。每一種都可以用篩選按鈕單獨顯示。

## Considered Options

- **左右兩個文字窗格的 diff**（像 VS Code）：最像原始檔案，但要自己處理兩邊補空行和同步捲動，也很容易誤改到旗標或英文。不採用。
- **兩種都做、可以切換**：開發量加倍，而表格已經能涵蓋所有需求。不採用。

## Consequences

- 英文行數跟翻譯行數不同的欄位（例如英文 2 行、翻譯 1 行，見 [ADR-0001](0001-lang-file-format.md)），沒辦法一行對一行拆列。這類欄位以「整個欄位一列」顯示，到下方詳細區編輯。實測 Chinese 對 Taiwan 有 49 列屬於這種情況。
