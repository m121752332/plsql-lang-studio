# 核心模組與畫面分離；寫回時只改翻譯行，未修改的檔案必須逐 byte 相同

格式解析、比對、工作區、用語表這些核心邏輯，都寫在不依賴 PySide6 的模組裡，畫面只負責呈現和操作。這樣核心邏輯可以直接拿 Languages 目錄裡的真實檔案做自動測試。

| 模組 | 負責 |
|---|---|
| `langcrypt.py` | 加解密 |
| `langfile.py` | 解析成「筆」、寫回原格式 |
| `compare.py` | 依識別碼對齊、判斷狀態 |
| `workspace.py` | 匯入、存檔、備份、部署、記事本 .txt 同步 |
| `glossary.py` | 用語對照表的讀寫與套用 |
| `ui/` | PySide6 畫面 |

`langfile.py` 寫回時只替換翻譯行（必要時同步更新旗標 p9–p11），檔頭、旗標、英文、說明註解都原樣保留。驗收標準：任何 `.lang` 解析後不做修改直接寫回，必須跟原檔逐 byte 相同。
