# 翻譯檢查規則：分成「錯誤」與「警告」兩級，殘留簡體字用 OpenCC 判斷並搭配例外詞

翻譯改錯，有些會讓程式出錯（例如佔位符 `%1` 不見了），有些只是用字不好。所以檢查分成兩級：

**錯誤（不能存檔）**

- 筆的格式壞了：旗標記錄的行數跟實際行數不符。
- 佔位符不一致：SLAVE 少了或多了英文原文裡的 `%1`～`%9`。Taiwan.lang 裡共有 1,004 個佔位符，少一個就可能顯示錯誤或讓程式出錯。

**警告（顯示在狀態欄，可以存檔）**

- 快速鍵 `&` 不見了：英文有 `&`，翻譯卻沒有。
- 疑似漏翻：翻譯跟英文原文完全一樣，而且英文含有 2 個以上連續的小寫字母，並排除網址、路徑、檔名。實測若只要求「含有英文字母」會標出 222 筆，大多是 DML、NLS 這類本來就不翻的縮寫；改用這條規則後剩 99 筆，大多是 Tablespace、Foreign key 這類真的還沒翻的詞。
- 殘留簡體字：字元 `c` 經過 OpenCC `s2t` 轉換後會變成別的字，就視為簡體字。
- 開頭或結尾的空白跟英文不一致。

**殘留簡體字的例外詞**：有些字在繁體中也是正確的。我們用現在的 Taiwan.lang 實測，標出 3 個字：

| 標出的字 | 出現位置 | 結果 |
|---|---|---|
| 游 | 游標 | 誤判，台灣正確用法 |
| 准 | 批准 | 誤判，台灣正確用法 |
| 后 | %1 天后過期 | **真的漏改**，應為「天後」 |

所以檢查時支援例外詞清單（預設含「游標」「批准」），比對的是「詞」而不是單一的字，才不會因為例外而漏掉真正的錯誤。例外詞存在 `glossary.json`，可以自行增減。
