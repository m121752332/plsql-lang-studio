# 批次操作一律先預覽、可以逐筆取消勾選，並且整批算成一個復原步驟

之前的手動替換經驗顯示，批次替換很容易誤傷其他詞，例如「新建」也出現在「重新建立表」裡，「通過計數」其實是測試的 Pass count。所以全文尋找取代、簡轉繁一鍵轉換、套用用語對照表這三種批次操作，都要經過同樣的流程：

1. 計算所有會受影響的字串，列出「識別碼｜英文｜修改前｜修改後」的預覽表，每一列都可以取消勾選。
2. 使用者按「套用」後，才寫進程式內的資料，被修改的字串標成 `✎`。這時還沒有存檔。
3. 整批操作是**一個**復原步驟，按一次 Ctrl+Z 就能全部還原。

批次操作只會改 SLAVE 的翻譯字串，不會動到英文、說明註解、識別碼或旗標。

**用語對照表**（`glossary.json`）每條規則包含：要找的詞、取代成什麼、例外（不要替換的上下文，例如「重新建立」），以及是否啟用。規則依清單順序套用，較長的詞要排在前面（例如「配置文件」排在「配置」前面）。編輯器提供「上移／下移」調整順序。

**簡轉繁**使用 OpenCC 的 `s2twp` 設定（台灣用字＋台灣用語），可以只轉換選取的列。
