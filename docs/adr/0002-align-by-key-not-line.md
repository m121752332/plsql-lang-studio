# MASTER 與 SLAVE 依「識別碼」對齊，不依行號

不同語言的 `.lang` 行數不一樣（Chinese 42,976 行、German 43,072 行），因為各語言翻譯的行數不同。如果用行號或文字 diff 對齊，捲動一段之後就會錯位。所以每一筆用「視窗名稱＋上層元件＋元件名稱＋元件類型」組成識別碼，比對器依識別碼配對 MASTER 和 SLAVE。

## Considered Options

- **依行號對齊**：最簡單，但只要有一筆翻譯行數不同，後面就全部錯位。不採用。
- **依筆的順序（第 n 筆對第 n 筆）**：版本相同的語言檔可行（13 個檔案都是 5,876 筆、順序一致）。但 Hungarian.lang 是 2024 年的舊版，只有 5,695 筆，順序也不同，依順序只有 256 筆能對上。不採用。

## Consequences

- 只有一邊有的筆，會標成「單邊」顯示，不會被丟掉。比對舊版語言檔時，可以藉此看出缺少或多出哪些筆。
- 如果同一個檔案裡出現重複的識別碼，要依出現順序加上序號再配對。
