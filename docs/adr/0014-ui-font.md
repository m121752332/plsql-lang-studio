# 字型與字體大小套用到整個介面，設定屬於程式本身

使用者需要調整介面的字型與字體大小，例如在高解析度螢幕上把字放大。我們選擇用 `QApplication.setFont` 套用到**整個介面**（表格、檔案清單、選單、詳細區、對話框），而不是只改表格，介面才會一致。

- `ui/fonts.py` 的 `FontManager` 負責套用與記住設定，介面上提供「配置 ▸ 配置… ▸ 外觀」頁面（ADR-0017 起從編輯選單移入）設定字型與大小，以及 Ctrl+加號／Ctrl+減號／Ctrl+0 快速鍵。
- 設定記在 `%APPDATA%\PLLangStudio\app.json` 的 `font_family`、`font_size` 欄位，跟主題一樣屬於程式本身，跟工作區無關（見 [ADR-0013](0013-theme-modes.md)）。空字串與 0 代表「使用系統預設」，所以「還原預設」能真正回到 Windows 的字型，而不是記住某個寫死的值。
- 字體大小限制在 7～32 pt。設定檔裡的值型別不對時視為預設，不讓壞掉的設定擋住程式啟動。
- 表格的列高原本寫死 22 px，改成依字型高度計算，字放大後才不會被切掉。

## Considered Options

- **只改表格與詳細區的字型**：翻譯內容變大了，選單和清單卻還是小字，看起來不一致。不採用。
- **用 Qt 內建的 QFontDialog**：選項太多（粗體、斜體、刪除線……），而且不能加「還原預設」。改用只有字型、大小、預覽的小對話框。
- **用 QSS 樣式表設定字型**：會蓋掉元件各自的字型設定，維護成本高。不採用。
