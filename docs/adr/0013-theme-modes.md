# 主題分成亮色、暗色、跟隨系統，每種主題都有自己的一組狀態色

使用者需要暗色主題，也需要跟著 Windows 的深淺色設定自動切換。但 ADR-0005 的經驗是：只換視窗的色盤，不換表格的狀態底色（淺黃、淺紅……），暗色主題下的白字就會看不見。所以 `ui/theme.py` 為亮色和暗色各準備一組完整的顏色，包括 Qt 色盤、狀態底色、同一筆的分組底色、主語系文字色、差異標色、殘留簡體字標色。表格和詳細區每次繪製時都讀取 `theme.colors()`，主題一變就整表重畫。

- **跟隨系統**：呼叫 `QStyleHints.unsetColorScheme()`，把深淺色交還給 Windows，並監聽 `colorSchemeChanged` 即時切換。明確選擇亮色或暗色時，則用 `setColorScheme()` 固定，讓 Windows 的視窗標題列也一起變色。
- 選擇記在 `%APPDATA%\PLLangStudio\app.json` 的 `theme` 欄位，預設是「跟隨系統」。這個設定屬於程式本身，跟工作區無關。
- 介面一律使用 Fusion 樣式，亮色和暗色在不同 Windows 版本上的外觀才會一致。

## Considered Options

- **只用 Qt 內建的深色樣式**：表格的狀態底色仍是寫死的淺色，問題沒有解決。不採用。
- **使用 QSS 樣式表**：要逐一覆蓋每種元件的樣式，維護成本高，而且狀態底色由 model 提供，樣式表管不到。不採用。
